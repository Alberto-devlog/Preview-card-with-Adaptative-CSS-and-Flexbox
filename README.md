### What I learned

I Think i learned so much in this project, i learned about what really are the fonts that we use to write and obviusly the difference between static and variable fonts. I'm very proud of learning how to use flexbox to position my designs, comparing to my previous work where i was forced to use absolute positioning by my lack of knowledge i think this project was very educational.

Code i'm proud of:

```css
body {
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  gap: 20px;
  min-height: 100vh;
  box-sizing: border-box;
}
```
